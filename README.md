# Kalorii

Щоденник калорій і білка — односторінковий застосунок для щоденного
обліку. Один самодостатній файл `index.html` — без збірки, без
залежностей, працює офлайн просто у браузері.

## Можливості

- Швидке додавання їжі з вбудованої бази продуктів (ваги — у готовому
  вигляді: крупи варені, риба сира) або вручну («Інше») з довільною назвою,
  калоріями та (за бажанням) білком.
- Позначка прийому їжі: Сніданок / Обід / Перекус / Вечеря.
- Перемикання між днями (‹ ›), кожен день зберігається окремо.
- Сумарні калорії й білок за день, прогрес-бар до денної цілі
  (зеленим — у межах цілі, червоним — перевищено).
- Редаговані денні цілі по калоріях і білку (кнопка «⚙» у шапці) — за
  замовчуванням 2137 ккал / 140 г білка.
- Видалення окремих записів.
- **Розпізнавання страви за фото** (кнопка «📷 Розпізнати за фото»): модель
  Claude визначає страву, оцінює вагу порції та калорії й білок, після чого
  заповнює поля запису — лишається перевірити й натиснути «Додати».

## Розпізнавання фото — налаштування

Ця функція викликає Anthropic API напряму з браузера, тому потрібен власний
API-ключ:

1. Відкрийте налаштування (кнопка «⚙»).
2. Вставте Anthropic API-ключ (`sk-ant-...`) — отримати можна на
   [console.anthropic.com](https://console.anthropic.com/settings/keys).
3. Оберіть модель: Opus 5 (найточніше), Sonnet 5 (швидше й дешевше) або
   Haiku 4.5 (найдешевше).

Ключ зберігається лише в `localStorage` цього браузера й надсилається
напряму в `api.anthropic.com` з вашого пристрою — жоден інший сервер його
не бачить. Через це сайт статичний (без бекенду) і не приховує ключ від
DevTools браузера — прийнятно для особистого використання, але ключ не варто
використовувати на спільному/чужому пристрої. Кожен виклик розпізнавання
фото — платний запит до Anthropic API за вашим тарифом.

## Зберігання даних

Усі записи, цільові показники та API-ключ зберігаються в `localStorage`
браузера — тобто локально на конкретному пристрої. Дані не синхронізуються
між пристроями. Записи щоденника й цілі нікуди не відправляються; фото
страви при розпізнаванні надсилається напряму в Anthropic API.

## Як перевірити локально

Відкрийте `index.html` у браузері (подвійний клік або `open index.html`).

## Як викласти онлайн

Найпростіший варіант — GitHub Pages:

- Settings → Pages → Source: гілка `main` / `/ (root)`.
- Сторінка буде доступна за адресою на кшталт
  `https://megaton2026.github.io/kalorii/`.
