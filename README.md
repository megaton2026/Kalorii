# Kalorii

Щоденник калорій і білка — односторінковий застосунок для щоденного
обліку. Один самодостатній файл `index.html` — без збірки, без
залежностей, працює офлайн просто у браузері.

## Можливості

- Швидке додавання їжі з вбудованої бази продуктів (ваги — у готовому
  вигляді: крупи варені, риба сира) або вручну («Інше») з довільною назвою,
  калоріями, білком, вуглеводами та жирами. **Пошук по назві** — почніть
  вводити текст у полі вибору страви, список одразу фільтрується (зручно,
  коли страв у базі й «Моїх стравах» стає багато).
- Позначка прийому їжі: Сніданок / Обід / Перекус / Вечеря.
- Перемикання між днями (‹ ›), кожен день зберігається окремо.
- Сумарні калорії за день, прогрес-бар до денної цілі (зеленим — у межах
  цілі, червоним — перевищено), і окремо білок / вуглеводи / жири з лімітом
  по кожному (число стає червоним при перевищенні).
- Редаговані денні цілі по калоріях, білку, вуглеводах і жирах (кнопка «⚙»
  у шапці) — за замовчуванням 2137 ккал / 140 г білка / 220 г вуглеводів /
  70 г жирів.
- Видалення окремих записів.
- **Розпізнавання страви за фото** (кнопка «📷 Розпізнати за фото»): модель
  Claude визначає страву, оцінює вагу порції, калорії, білок, вуглеводи й
  жири, після чого заповнює поля запису — лишається перевірити й натиснути
  «Додати». При зміні ваги всі показники перераховуються пропорційно
  автоматично.
- Будь-яка страва, додана вручну чи через фото з вказаною вагою, автоматично
  потрапляє у список «Мої страви» у випадаючому меню — наступного разу її
  можна просто вибрати й ввести нову вагу, без повторного розпізнавання чи
  введення калорій.
- **Історія по днях** (кнопка «📜» у шапці): список усіх днів, коли щось було
  додано, з сумою калорій, білка і денним балансом (дефіцит/профіцит) —
  тап по дню одразу відкриває його.
- **Облік спалених калорій і баланс дня**: поле «Активні калорії» (з
  фітнес-трекера чи вручну) на головному екрані. Базовий обмін (BMR —
  скільки організм спалює в стані спокою) задається один раз у налаштуваннях
  (⚙ → «Спалені калорії», можна порахувати за формулою з ваги/зросту/віку/
  статі) і додається автоматично щодня. Показує різницю між з'їденим і
  спаленим — дефіцит (зелений) або профіцит (червоний).
- **Зведення** (кнопка «📜»): поточний тиждень і місяць одним поглядом, а
  нижче — повна історія балансу **по кожному тижню** та **по кожному
  місяцю** окремо (не тільки поточні), щоб бачити тренд.
- **Вага тіла** (кнопка «⚖» у шапці): одне поле — вводите вагу за сьогодні,
  застосунок будує графік динаміки, рахує зміну за весь час і за останні
  30 днів, і показує середню вагу та зміну **по кожному тижню** й **по
  кожному місяцю** окремо (не тільки загалом) — плюс повний список записів
  по днях із видаленням окремих.
- **Аналіз нутриціолога** (кнопка «🥗» у шапці, потребує Anthropic API-ключ):
  Claude аналізує раціон за останні 7 днів — баланс БЖВ (білки/жири/
  вуглеводи), орієнтовне забезпечення вітамінами й мінералами (на основі
  типового складу з'їдених продуктів) — і дає 3–5 конкретних порад на
  наступний тиждень. Результат кешується, щоб не робити зайвих платних
  запитів при кожному відкритті; кнопка дозволяє оновити аналіз вручну. Це
  орієнтовний AI-аналіз, не медична консультація.
- Експорт/імпорт усіх даних у `.json`-файл (кнопка «⚙» → «Резервна копія»).

## Розпізнавання фото — налаштування

Ця функція викликає Anthropic API напряму з браузера, тому потрібен власний
API-ключ:

1. Відкрийте налаштування (кнопка «⚙»).
2. Вставте Anthropic API-ключ (`sk-ant-...`) — отримати можна на
   [console.anthropic.com](https://console.anthropic.com/settings/keys).
3. Оберіть модель: Opus 5 (найточніше), Sonnet 5 (швидше й дешевше) або
   Haiku 4.5 (найдешевше).

Ключ зберігається лише в `localStorage` цього браузера й надсилається
напряму в `api.anthropic.com` з вашого пристрою — жоден інший сервер його
не бачить. Через це сайт статичний (без бекенду) і не приховує ключ від
DevTools браузера — прийнятно для особистого використання, але ключ не варто
використовувати на спільному/чужому пристрої. Кожен виклик розпізнавання
фото — платний запит до Anthropic API за вашим тарифом.

## Зберігання даних і як зберегти історію надовго

Усі записи, цільові показники та API-ключ зберігаються в `localStorage`
браузера — тобто локально на конкретному пристрої. Дані не синхронізуються
між пристроями. Записи щоденника й цілі нікуди не відправляються; фото
страви при розпізнаванні надсилається напряму в Anthropic API.

`localStorage` сам по собі не має терміну дії, але деякі браузери (особливо
Safari на iOS) можуть самі очистити сховище сайту, якщо ним довго не
користуватись (політика захисту від трекінгу) або при нестачі місця на
пристрої. Щоб історія надійно зберігалась місяцями:

1. **Додайте сайт на екран Початку** (у Safari на iPhone: кнопка «Поділитись»
   → «На екран «Початок»»). Це відкриває застосунок в окремому режимі, на
   який не поширюється очищення сховища звичайних вкладок Safari.
2. Застосунок сам просить браузер зробити сховище «постійним»
   (`navigator.storage.persist()`) — підтримується в Chrome/Android,
   Safari цю можливість ігнорує.
3. Час від часу робіть експорт (⚙ → «Резервна копія») — це найнадійніший
   спосіб не втратити історію, навіть якщо браузер усе ж очистить сховище.

Переглянути всю історію одразу (а не гортати день за днем) можна в розділі
«📜 Історія» — список усіх збережених днів із сумами, з переходом по тапу.

## Як перевірити локально

Відкрийте `index.html` у браузері (подвійний клік або `open index.html`).

Найпростіший варіант — GitHub Pages:

- Settings → Pages → Source: гілка `main` / `/ (root)`.
- Сторінка буде доступна за адресою на кшталт
  `https://megaton2026.github.io/kalorii/`.
